# 产品销量优化与库存管理系统 - 项目交付说明

## 📦 项目概述

基于你的需求说明书开发完成的 **Windows 桌面端应用**，用于产品销量优化与库存管理。

- **技术栈**: C# + WinForms + .NET 8.0
- **优化引擎**: Google OR-Tools（强大的开源线性规划求解器）
- **Excel处理**: EPPlus（免费开源）
- **运行环境**: Windows 10/11，无需联网，纯本地运行

## 🎯 已实现功能

### ✅ 1. Excel 导入功能
- 支持导入产品信息（编码、名称、单价、描述）
- 支持导入月度数据（需求、库存等）
- 自动解析和验证数据格式

### ✅ 2. 产品基础管理
- 支持 80+ 产品管理
- 单价可修改、保存
- 产品新增、编辑、删除
- 数据网格展示，支持排序

### ✅ 3. 数据输入
- 每个产品：月度需求量
- 每个产品：月末目标库存
- 每个产品：月初实际库存
- 全局约束：本月可供应/生产的总数量上限
- 全局目标：需要达成的总销售额

### ✅ 4. 核心计算逻辑（约束优化）
使用 **Google OR-Tools 线性规划求解器**：
- **硬约束**：总供应量上限（严格遵守）
- **软约束**：尽可能满足月度需求
- **目标函数**：最大化销售额 + 惩罚未满足的需求

**计算结果**：
- 每个产品建议销量/产量
- 预计总销售额
- 与目标销售额的差额
- 是否满足供应量约束
- 求解状态（最优解/可行解/无解）

### ✅ 5. 结果输出
- 数据网格展示所有产品优化详情
- 汇总面板显示关键指标
- 一键导出到 Excel（包含三个工作表）：
  - 汇总信息
  - 产品明细
  - 原始数据

### ✅ 6. 界面设计
- 简洁现代的 Windows 桌面界面
- 选项卡式布局（产品管理 | 月度数据 | 计算结果）
- 工具栏快捷操作
- 状态栏实时提示
- 高DPI支持

## 🚀 快速开始

### 方式一：使用 Visual Studio 2022
1. 安装 Visual Studio 2022（勾选 ".NET 桌面开发"）
2. 双击 `ProductInventoryOptimizer.csproj` 打开项目
3. Visual Studio 自动还原 NuGet 包
4. 按 F5 运行

### 方式二：使用 .NET CLI
```bash
# 安装 .NET 8.0 SDK
# https://dotnet.microsoft.com/download/dotnet/8.0

# 进入项目目录
cd InventoryOptimizationSystem

# 还原依赖
dotnet restore

# 编译运行
dotnet run
```

### 打包为独立可执行文件
```bash
dotnet publish -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
```

生成的可执行文件在：
`bin/Release/net8.0-windows/win-x64/publish/ProductInventoryOptimizer.exe`

## 📊 使用流程

### 第一次使用（手动输入数据）
1. 打开程序，系统会自动加载示例数据（80个产品）
2. 在"产品管理"选项卡中修改产品信息（单价、描述等）
3. 在"月度数据"选项卡中录入各产品的需求和库存数据
4. 在顶部输入"本月可供应总数"和"目标销售额"
5. 点击"开始计算"按钮
6. 查看"计算结果"选项卡，可导出Excel

### 第二次及以后（Excel导入）
1. 准备符合模板格式的 Excel 文件
2. 点击"导入Excel"按钮选择文件
3. 系统自动解析并填充数据
4. 设置供应量和销售目标后计算

### 可能的"无解"情况
以下情况可能导致优化无解：
1. 月末库存要求过高，超过供应能力
2. 总供应量限制太紧，无法满足所有需求
3. 需求量计算错误（异常大）

**解决方法**：调整供应量上限、降低库存目标或检查需求数据

## 🛠️ 核心技术说明

### 线性规划模型
```
变量：x_i = 产品i的销售/生产数量（整数）

目标函数：
最大化 ∑ (单价_i × x_i) - 惩罚 × (需求未满足量_i)

约束：
1. ∑ x_i ≤ 最大供应总量（硬约束）
2. x_i + 需求未满足量_i ≥ 需求量_i（软约束，通过惩罚实现）
```

### 优化策略
- **主目标**: 在供应量约束下最大化销售额
- **次目标**: 尽可能满足各产品需求（通过大权重惩罚未满足的需求）
- **求解器**: CBC（Coin-or Branch and Cut），成熟高效的混合整数规划求解器
