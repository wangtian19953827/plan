# 安装包脚本 - 完成说明

**产品销量优化与库存管理系统**

## ✅ 已创建的脚本

以下所有脚本已成功创建，位于 `scripts/` 目录：

### 1. install.bat - 一键安装构建
- **用途**: 检查环境并启动自动构建
- **特点**: 自动检测 .NET SDK，未安装会提示下载
- **输出**: `Release_Package/` 目录

### 2. build.bat - Windows 批处理构建
- **用途**: 主构建脚本，编译并打包项目
- **特点**: 中文界面，自动打开发布文件夹
- **输出**: `Release_Package/` 目录

### 3. build.ps1 - PowerShell 构建（推荐）
- **用途**: 功能更强大的构建脚本
- **特点**: 彩色输出，显示文件大小，详细错误信息
- **输出**: `Release_Package/` 目录

### 4. build_debug.bat - 开发版快速构建
- **用途**: 快速构建并运行（调试版本）
- **特点**: Debug 配置，自动运行程序
- **适合**: 开发测试

### 5. create_installer.bat - 创建安装包
- **用途**: 从构建文件创建安装包
- **输出**: `Installer/` 目录
- **包含**: 程序文件 + README + 卸载脚本

### 6. create_zip.ps1 - 创建 ZIP 分发包
- **用途**: 创建标准 ZIP 安装包（推荐分发）
- **输出**: `ProductInventoryOptimizer_v1.0.0_YYYYMMDD.zip`
- **包含**: 程序文件 + 文档 + 安装说明 + 卸载脚本

### 7. scripts/使用说明.md - 详细脚本使用指南
- **用途**: 脚本使用的完整文档
- **内容**: 详细说明、常见问题、高级用法

## 🚀 快速使用

### 最简单的方式（推荐）

```bash
# 1. 进入 scripts 目录
cd InventoryOptimizationSystem\scripts

# 2. 运行一键构建
install.bat
```

### 生成可分发的 ZIP 包

```bash
# 1. 构建
install.bat

# 2. 创建 ZIP
create_zip.ps1
```

生成的 ZIP 文件可以直接分发给用户！

## ⚠️ 注意事项

### 前置条件
- 必须在 Windows 10/11 系统上运行
- 必须安装 .NET 8.0 SDK

### PowerShell 脚本执行策略
如果无法运行 .ps1 脚本，需要临时允许：

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
```
