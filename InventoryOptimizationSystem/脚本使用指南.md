# 安装包脚本使用说明

## 📦 脚本文件列表

项目包含完整的自动化构建和打包脚本，位于 `scripts/` 目录：

| 脚本文件 | 说明 | 适用平台 |
|----------|------|----------|
| `install.bat` | 一键安装构建脚本 | Windows |
| `build.bat` | Windows 批处理构建脚本 | Windows (cmd) |
| `build.ps1` | PowerShell 构建脚本 | Windows (PowerShell) |
| `build_debug.bat` | 开发版快速构建脚本 | Windows |
| `create_installer.bat` | 创建安装包 | Windows |
| `create_zip.ps1` | 创建 ZIP 分发包 | Windows (PowerShell) |
| `使用说明.md` | 详细脚本使用指南 | - |

---

## 🚀 快速开始

### 一键构建（推荐）

如果你已经安装了 .NET 8.0 SDK：

```bash
# Windows 命令提示符/PowerShell
cd InventoryOptimizationSystem\scripts
install.bat
```

**这个脚本会自动完成**：
1. ✅ 检查 .NET SDK 是否安装
2. ✅ 还原 NuGet 包
3. ✅ 编译项目
4. ✅ 打包为独立 EXE
5. ✅ 整理发布文件到 `Release_Package/` 目录
6. ✅ 自动打开发布文件夹

---

## 📋 各脚本详细说明

### 1. install.bat - 一键安装构建

**用途**：检查环境并启动自动构建

**使用**：
```bash
cd InventoryOptimizationSystem\scripts
install.bat
```

**功能**：
- 检测操作系统（仅支持 Windows）
- 检测 .NET SDK（未安装会自动打开下载页面）
- 自动调用 `build.bat` 执行构建

**适合场景**：第一次使用，不确定环境是否完整

---

### 2. build.bat - Windows 批处理构建

**用途**：主构建脚本，编译并打包项目

**使用**：
```bash
cd InventoryOptimizationSystem\scripts
build.bat
```

**输出目录**：
```
Release_Package/
├── ProductInventoryOptimizer.exe  (独立 EXE)
├── 快速启动.md
├── Excel模板说明.md
└── 项目说明.md
```

**特点**：
- 中文界面
- 自动打开 Release_Package 文件夹
- 显示详细的构建步骤

---

### 3. build.ps1 - PowerShell 构建（推荐）

**用途**：功能更强大的 PowerShell 构建脚本

**使用**：
```powershell
cd InventoryOptimizationSystem\scripts
.\build.ps1
```

**优势**：
- ✅ 彩色输出（更清晰）
- ✅ 更详细的错误信息
- ✅ 显示文件大小
- ✅ 更好的进度提示

**输出文件**：同 `build.bat`

---

### 4. build_debug.bat - 开发版快速构建

**用途**：快速构建并运行（调试版本）

**使用**：
```bash
cd InventoryOptimizationSystem\scripts
build_debug.bat
```

**特点**：
- Debug 配置（包含调试信息）
- 自动运行程序
- 适合开发测试和调试

---

### 5. create_installer.bat - 创建安装包

**用途**：从构建文件创建安装包

**前置条件**：必须先运行 `build.bat` 或 `build.ps1`

**使用**：
```bash
cd InventoryOptimizationSystem\scripts
create_installer.bat
```

**输出**：
```
Installer/
├── ProductInventoryOptimizer/      (程序文件)
├── README.txt                      (安装说明)
└── uninstall.bat                   (卸载脚本)
```

**适合场景**：将 `Installer/` 文件夹打包为 ZIP 分发给用户

---

### 6. create_zip.ps1 - 创建 ZIP 分发包（推荐）

**用途**：创建标准 ZIP 安装包

**前置条件**：必须先运行 `build.bat` 或 `build.ps1`

**使用**：
```powershell
cd InventoryOptimizationSystem\scripts
.\create_zip.ps1
```

**输出**：
```
ProductInventoryOptimizer_v1.0.0_20240224.zip
```

**ZIP 内容**：
```
Product-Installer/
├── ProductInventoryOptimizer/      (程序文件夹)
│   ├── ProductInventoryOptimizer.exe
│   ├── 快速启动.md
│   ├── Excel模板说明.md
│   └── 项目说明.md
├── README.txt                      (安装说明)
└── uninstall.bat                   (卸载脚本)
```

**适合场景**：最终分发，用户解压后直接运行

## 🔧 高级用法

### 手动构建（不使用脚本）

如果你更熟悉 .NET CLI：

```bash
# 1. 还原包
dotnet restore

# 2. 打包为独立 EXE
dotnet publish -c Release -r win-x64 --self-contained -p:PublishSingleFile=true

# 3. EXE 位置
bin\Release\net8.0-windows\win-x64\publish\ProductInventoryOptimizer.exe
```

### 自定义打包参数

编辑 `build.bat` 或 `build.ps1`，修改 `dotnet publish` 命令参数：

```bash
# 单文件打包（默认）
-p:PublishSingleFile=true

# 压缩程序集
-p:EnableCompressionInSingleFile=true

# 减小文件大小（使用裁剪）
-p:PublishTrimmed=true
```

## ❓ 常见问题

### Q1: 运行脚本时提示 "找不到 dotnet 命令"

**A**: 未安装 .NET 8.0 SDK
- 下载：https://dotnet.microsoft.com/download/dotnet/8.0
- 安装 ".NET 8.0 SDK"（不是 Runtime）
- 安装后重启命令行窗口

### Q2: PowerShell 脚本无法运行

**A**: 执行策略限制

```powershell
# 临时允许（推荐）
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process

# 然后运行脚本
.\build.ps1
```

### Q3: 构建成功但 EXE 无法运行

**A**: 检查目标机器
- 确认是 Windows 10/11
- 确认有足够内存（4GB+）
- 尝试以管理员身份运行

### Q4: 想要更小的 EXE 文件

**A**: 使用依赖框架版本

```bash
dotnet publish -c Release -r win-x64

# 然后在目标机器上安装 .NET 8.0 Runtime
```

### Q5: 如何更新程序版本号

**A**: 编辑 `ProductInventoryOptimizer.csproj`

```xml
<PropertyGroup>
  <Version>1.0.1</Version>
  <!-- ... -->
</PropertyGroup>
```
