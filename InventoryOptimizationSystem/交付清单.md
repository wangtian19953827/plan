## 🚀 快速验证步骤

### 第1步：环境准备
1. 安装 .NET 8.0 SDK
   https://dotnet.microsoft.com/download/dotnet/8.0

2. 验证安装
   ```bash
   dotnet --version
   ```

### 第2步：还原依赖
```bash
cd InventoryOptimizationSystem
dotnet restore
```

### 第3步：编译运行
```bash
dotnet run
```

### 第4步：功能测试
- [ ] 程序正常启动
- [ ] 看到80个示例产品
- [ ] 点击"开始计算"，看到计算结果
- [ ] 点击"导出结果"，成功生成Excel

### 第5步：打包部署（可选）
```bash
dotnet publish -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
```

生成的EXE可直接分发使用。

## 💡 使用技巧

### 快速导入数据
1. 运行 `python create_sample_excel.py` 生成示例Excel
2. 在程序中点击"导入Excel"
3. 选择生成的 `sample_data.xlsx`

### 批量设置月度数据
1. 在"月度数据"选项卡
2. 点击"批量设置"按钮
3. 一次性设置所有产品的需求量和库存

### 导出后的Excel
包含三个工作表：
- 汇总信息：总体计算结果
- 产品明细：每个产品的详细数据
- 原始数据：导入的原始数据
