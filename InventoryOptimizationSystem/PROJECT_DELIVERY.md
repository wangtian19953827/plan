## 🚀 立即开始使用

### 方式一：命令行快速启动（推荐）

```bash
# 1. 进入项目目录
cd InventoryOptimizationSystem

# 2. 还原依赖包
dotnet restore

# 3. 运行程序
dotnet run
```

### 方式二：使用 Visual Studio

1. 双击 `ProductInventoryOptimizer.csproj`
2. 按 F5 运行

### 方式三：打包为独立 EXE

```bash
dotnet publish -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
```

生成的 `ProductInventoryOptimizer.exe` 可直接在任何 Windows 10/11 机器上运行。

## 🎯 功能演示流程

### 第1步：打开程序
运行后自动加载80个示例产品，可直接测试。

### 第2步：修改产品信息（可选）
- 切换到"产品管理"选项卡
- 添加/编辑/删除产品
- 修改产品单价

### 第3步：设置月度数据
- 切换到"月度数据"选项卡
- 逐个编辑或批量设置需求数据
- 设置月初库存和月末目标库存

### 第4步：设置全局参数
- 在顶部输入"本月可供应总数"（如：10000）
- 输入"目标销售额"（如：500000）

### 第5步：执行优化计算
- 点击"开始计算"按钮
- 等待计算（<1秒）
- 查看计算结果

### 第6步：导出结果
- 点击"导出结果"按钮
- 选择保存位置
- 得到包含三个工作表的Excel文件

### 第7步：导入新数据（可选）
- 点击"导入Excel"
- 选择符合模板的Excel文件
- 系统自动解析并填充数据
