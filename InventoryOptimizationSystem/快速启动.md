# 快速启动指南

## 给程序员的快速交接

### 1. 立即可用的完整项目
项目位于：`InventoryOptimizationSystem/` 目录

### 2. 需要安装的工具
- **Visual Studio 2022**（推荐）或 **.NET 8.0 SDK**
- 下载 .NET 8.0：https://dotnet.microsoft.com/download/dotnet/8.0

### 3. 三步运行
```bash
# 进入项目目录
cd InventoryOptimizationSystem

# 还原NuGet包
dotnet restore

# 运行
dotnet run
```

### 4. 使用自动化脚本（推荐）

如果已安装 .NET 8.0 SDK，Windows 下可以一键构建：

```bash
# 进入 scripts 目录
cd scripts

# 一键构建
install.bat
```

生成的独立 EXE 位于：`Release_Package\ProductInventoryOptimizer.exe`

### 5. 在 Visual Studio 中打开
1. 双击 `ProductInventoryOptimizer.csproj`
2. 按 F5 运行

### 6. 打包为独立 EXE（可分发）
```bash
dotnet publish -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
```
生成的文件：`bin/Release/net8.0-windows/win-x64/publish/ProductInventoryOptimizer.exe`

这个 EXE 可以直接在任何 Windows 10/11 机器上运行（无需安装 .NET）

### 7. 创建 ZIP 分发包（用于分发）

```bash
# 1. 先构建
cd scripts
install.bat

# 2. 创建 ZIP 包
create_zip.ps1
```

生成的文件：`ProductInventoryOptimizer_v1.0.0_YYYYMMDD.zip`（可直接分发给用户）

**详细脚本说明**：`scripts/使用说明.md`

## 常见问题

### Q: 提示"找不到 .NET SDK"
**A**: 安装 .NET 8.0 SDK：https://dotnet.microsoft.com/download/dotnet/8.0

### Q: 编译时提示缺少包
**A**: 运行 `dotnet restore` 还原 NuGet 包

### Q: 运行时报错 DLL 加载失败
**A**: 使用 `dotnet publish --self-contained` 打包，或安装 .NET 8.0 Runtime

### Q: 优化计算显示"无解"
**A**: 检查约束条件：
- 供应量上限是否合理
- 需求量是否异常大
- 月末库存目标是否过高
