# 产品销量优化与库存管理系统 - 编译运行指南

## 环境要求

### 方式一：Visual Studio 2022（推荐）
1. 安装 Visual Studio 2022 Community/Professional/Enterprise
2. 安装时勾选 ".NET 桌面开发" 工作负载

### 方式二：.NET SDK 8.0
1. 下载并安装 .NET 8.0 SDK
   - 下载地址：https://dotnet.microsoft.com/download/dotnet/8.0
2. 验证安装：打开命令行，运行 `dotnet --version` 应显示 8.0.x

## 编译步骤

### 使用 Visual Studio
1. 双击打开 `ProductInventoryOptimizer.csproj`
2. Visual Studio 会自动还原 NuGet 包
3. 按 F5 或点击"开始调试"按钮运行

### 使用命令行
```bash
# 进入项目目录
cd InventoryOptimizationSystem

# 还原 NuGet 包
dotnet restore

# 编译项目
dotnet build

# 运行程序
dotnet run
```

## 发布打包

### 打包为独立可执行文件
```bash
# 发布为单文件
dotnet publish -c Release -r win-x64 --self-contained -p:PublishSingleFile=true

# 发布文件位于：bin/Release/net8.0-windows/win-x64/publish/
```

### 打包为依赖框架的可执行文件
```bash
# 发布（需要目标机器安装 .NET 8.0 Runtime）
dotnet publish -c Release -r win-x64

# 发布文件位于：bin/Release/net8.0-windows/win-x64/publish/
```

## 常见问题

### Q1: 编译时提示 "找不到类型或命名空间"
**A**: 确保已还原 NuGet 包：`dotnet restore`

### Q2: 运行时报错 "无法加载 DLL 'ortools'..."
**A**: Google OR-Tools 需要原生库支持。使用命令行发布时建议使用 `--self-contained` 参数。

### Q3: Excel 导入失败
**A**: 检查 Excel 文件格式是否符合模板要求，确保第一行为表头。

### Q4: 优化计算无解
**A**: 检查约束条件是否冲突，例如：
- 月末库存要求过高
- 总供应量限制太紧
- 需求量超过供应能力
